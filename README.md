# 🏠 Bem-vindo ao meu Site

Este site foi gerado automaticamente a partir de ficheiros **Markdown** utilizando o Docsify, o GitHub e a Vercel.

## 🚀 Como funciona?
Qualquer alteração feita nos ficheiros `.md` reflete-se instantaneamente no site assim que enviar para o GitHub.

### Subtítulo de Teste
Este subtítulo vai aparecer na barra lateral automaticamente devido à configuração `subMaxLevel: 2`.
