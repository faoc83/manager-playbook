# Performance Management

## Visão Geral

Performance management é um processo contínuo entre manager e engineer.

## Componentes

### 1. Setting Expectations
- Definir deliverables, qualidade e comportamento
- Alinhar com objetivos da equipa

### 2. Feedback Contínuo
- Frequente (semanalmente)
- Específico e accionável

### 3. Performance Reviews
- Quarterly ou bi-annually
- Self + manager assessment

### 4. PIP
- Último recurso
- 30-60-90 days

## Métricas

- SPACE Framework
- DORA Metrics
