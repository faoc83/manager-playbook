# Engineering Maturity Matrix - Detailed

## 📊 Complete Framework

### Level 1: Junior Engineer

**Tenure:** 0-2 years (típico)

| Dimension | Expectations | Examples |
|-----------|-------------|----------|
| **Technical** | Completa tasks bem definidas com guidance | Implementa features pequenas, segue padrões existentes |
| **Problem Solving** | Resolve problemas conhecidos, pede help para novos | Usa Stack Overflow, docs, pede ajuda após tentar |
| **Communication** | Comunica status e blockers | Updates em standups, Slack quando bloqueado |
| **Collaboration** | Participa ativamente, receptive a feedback | Code reviews, pair programming, aceita feedback |
| **Ownership** | Owns assigned tasks | Completa stories, reporta issues |
| **Impact** | Individual contributor | Impacto no próprio trabalho |

**Promo Signals:**
- Consistentemente entrega sem rework significativo
- Pede help cedo e apropriadamente
- Começa a mentorar interns/very juniors
- Entende sistema além das próprias tasks

---

### Level 2: Mid-Level Engineer

**Tenure:** 2-4 years (típico)

| Dimension | Expectations | Examples |
|-----------|-------------|----------|
| **Technical** | Design e implementa features completas | Owns features end-to-end, escolhe abordagens |
| **Problem Solving** | Resolve problemas complexos na própria área | Debug issues, propõe soluções |
| **Communication** | Comunica proativamente, documenta | Escreve docs, apresenta em team meetings |
| **Collaboration** | Colabora com peers, dá feedback | Reviews de qualidade, ajuda juniors |
| **Ownership** | Owns features e pequenos projetos | Gerencia dependências, pensa em trade-offs |
| **Impact** | Team-level | Impacto na própria equipa |

**Promo Signals:**
- Entrega features complexas com mínima supervisão
- Antecipa problemas e comunica stakeholders
- Mentor informal de juniors
- Contribui para melhorias de processo/tooling

---

### Level 3: Senior Engineer

**Tenure:** 4-8 years (típico)

| Dimension | Expectations | Examples |
|-----------|-------------|----------|
| **Technical** | Design de sistemas, best practices | Arquiteta serviços, define padrões |
| **Problem Solving** | Resolve problemas ambíguos e complexos | Systems thinking, trade-off analysis |
| **Communication** | Comunica com stakeholders, influencia | Apresenta para leadership, write-ups |
| **Collaboration** | Cross-team collaboration, resolve conflitos | Trabalha com product, design, outras eng teams |
| **Ownership** | Owns sistemas ou áreas | Roadmap planning, technical strategy |
| **Impact** | Team e org-level | Impacto além da própria equipa |

**Promo Signals:**
- Lead de iniciativas técnicas significativas
- Mentor ativo de mid-level engineers
- Influencia direção técnica da equipa/org
- Balança trade-offs técnicos e de negócio

---

### Level 4: Staff Engineer

**Tenure:** 8+ years (típico)

| Dimension | Expectations | Examples |
|-----------|-------------|----------|
| **Technical** | Arquitetura org-wide, define standards | System design crítico, tech strategy |
| **Problem Solving** | Problemas mais complexos da org | Resolve blockers organizacionais |
| **Communication** | Comunica visão, alinha execs | Tech talks, strategy docs, all-hands |
| **Collaboration** | Org-wide e cross-functional | Partner com VP, Product, Business |
| **Ownership** | Strategic initiatives | Multi-quarter, multi-team projects |
| **Impact** | Organization-wide | Impacto em toda a engenharia ou company |

**Promo Signals:**
- Impacto consistente além da própria org
- Define direção técnica para a company
- Develops outros senior/staff engineers
- Resolve problemas que bloqueiam a organização

---

## 🎯 Assessment Rubric

### Technical Excellence

| Level | Criteria |
|-------|----------|
| 1 | Code funciona, precisa de review detalhado |
| 2 | Code quality consistente, boas práticas |
| 3 | Design patterns, system thinking, best practices |
| 4 | Architecture decisions, org-wide standards |

### Delivery

| Level | Criteria |
|-------|----------|
| 1 | Entrega tasks com guidance |
| 2 | Entrega features previsivelmente |
| 3 | Entrega valor em iniciativas complexas |
| 4 | Entrega impacto estratégico multi-team |

### Leadership

| Level | Criteria |
|-------|----------|
| 1 | Participa, aprende |
| 2 | Colabora, ajuda peers |
| 3 | Mentors, influencia team direction |
| 4 | Develops leaders, org influence |
